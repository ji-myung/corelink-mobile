## 1. 접수할 파일

**`02_인쇄소_접수용/` 안의 파일**만 보내시면 됩니다. 받는 형식에 맞춰 두 가지를 같이 넣어 두었으니 **하나만 고르시면 됩니다.**

| 받는 형식 | 쓸 파일 |
|---|---|
| **PDF** (작업사이즈, 1p 앞·2p 뒤) — 권장 | `..._CMYK_양면_{{작업파일}}_{{dpi}}dpi.pdf` |
| **AI 또는 EPS** (빠른접수) | `..._front_CMYK_...eps` + `..._back_CMYK_...eps` |

```
01_시안_4K/              눈으로 보는 확인용 PNG. 접수용 아님
02_인쇄소_접수용/         ← 이 안에서 하나만 골라 접수
   ..._CMYK_양면_{{작업파일}}_{{dpi}}dpi.pdf   PDF 접수용 (1p 앞 · 2p 뒤)
   ..._front_CMYK_{{작업파일}}_{{dpi}}dpi.eps  EPS 접수용 앞면
   ..._back_CMYK_{{작업파일}}_{{dpi}}dpi.eps   EPS 접수용 뒷면
03_기타_PDF_PNG/         참고용. 벡터 RGB PDF(양면·낱장), 재단선 포함 PDF, {{dpi}}dpi RGB PNG
04_QR/                   QR 단독 파일과 담긴 주소
README_인쇄사양.md        이 문서
```

`03_기타` 는 참고용입니다. **접수에 쓰지 마세요** — RGB 이고, 재단선 포함 파일에는 가이드가 금지하는 안내선이 들어 있습니다.

## 2. 접수 규격 대조

작업파일 가이드(접수파일 작업방법 · 공통 작업방법 · 명함 작업방법)의 항목과 이 파일의 상태입니다.

| 가이드 요구 | 이 파일 |
|---|---|
| 파일 형식: AI · EPS · PDF · JPG(ZIP) | **PDF**(1p 앞·2p 뒤)와 **EPS**(면당 1장) 둘 다 넣었습니다 |
| 색상모드 **CMYK**, RGB·별색 금지 | **DeviceCMYK 8bit**. RGB 요소 없음, 별색 없음 |
| **총 잉크량 250% 이하** (뒷묻음 재작업 불가 조항) | {{잉크량}} |
| **K100 단색은 자동 오버프린트** — 밑색이 비쳐 보임 | {{K100}} |
| 서체 **전부 윤곽선(아웃라인)** | 글자가 화소로 들어가 있어 폰트가 아예 없습니다. 임의 서체로 바뀔 여지 없음 |
| 작업사이즈 (재단 + 사방 {{도련}} 여유분) | **정확히 {{작업mm}}** = {{pt}} pt = {{화소}} @{{dpi}}dpi |
| 안전영역: 재단에서 **4mm 안쪽** | {{안전여유}} |
| 재단선·작업선·안내선을 **그려 넣지 말 것** | 접수용에는 선이 없습니다 |
| 효과(그림자·그라데이션·투명도)는 **300dpi 이상 CMYK 로 래스터화** | 전면을 **{{dpi}}dpi CMYK** 로 래스터화. 살아 있는 효과·투명도 없음 |
| 이미지는 **포함(embed)**, 작업사이즈까지만 | 화소가 파일 안에 들어 있습니다(링크 없음). 작업사이즈 밖으로 넘치는 것 없음 |
| 잠금(Lock) 해제 후 앞·뒷면 각각 **그룹 지정** | 개체가 없는 단일 이미지라 잠기거나 유실될 조각이 없습니다 |
| 양면 배열: 앞면 1페이지 / 뒷면 2페이지 | PDF 가 **1p 앞 · 2p 뒤**. EPS 는 파일명으로 구분(`_front` / `_back`) |
| 여러 파일은 폴더에 담아 **ZIP** 으로 접수 | 패키지 zip 이 함께 들어 있습니다 |

**AI(.ai) 네이티브 파일은 넣지 못했습니다.** Illustrator 로만 만들 수 있습니다.
가이드가 PDF·EPS 도 받으므로 그쪽으로 냈고, AI 만 받는다고 하면 EPS 를 Illustrator 에서 열어 저장하면 됩니다.

## 4. 색상 — 이미 CMYK 입니다

접수용 파일은 **DeviceCMYK 로 이미 변환되어 있습니다. 다시 변환하지 말아 주세요.**

| 요소 | CMYK | 합 | 비고 |
|---|---|---|---|
| 배경 검정 | **C60 M40 Y40 K100** (리치 블랙) | 240% | 넓은 면적이라 K 단색으로 찍으면 회색빛으로 뜹니다. 파일에 이미 리치 블랙으로 들어가 있음 |
| 골드 (기본) | C0 M28 Y66 K6 | 100% | 로고 E, 직함, 라인, × 표시 |
| 골드 (진함) | C0 M26 Y63 K17 | 106% | 세로 구분선, QR 테두리 |
| 골드 (밝음) | C0 M20 Y56 K3 | 79% | 라인 중앙·점, 곡선 매듭 하이라이트 |
| 흰 글자 | C0 M0 Y0 K2 | 2% | 로고, 이름·서비스·연락처 |
| QR 바탕 | C0 M0 Y1 K3 | 4% | |
| QR 모듈 | **K 단색 (K93, CMY 0)** | 93% | 모듈이 아주 작아 4도로 찍으면 판이 어긋나며 흐려집니다. 일부러 K 단색으로 두었습니다 |

**뒷묻음** — 가장 진한 곳이 240% 로 가이드 상한(250%) 안입니다. 그래도 검정 베다라 무광 코팅을 권합니다.

**재단 뜯김** — 바탕이 진한 베다라 재단 시 뜯김이 생길 수 있습니다. 칼 상태를 봐 주시면 좋겠습니다.

**금·은박 옵션** — 금박은 **FOCOLTONE 1150**, 은박은 **FOCOLTONE 2250** 으로 지정하시면 됩니다.
박으로 뽑을 부분은 앞면 로고의 E 막대 3개·글로우 라인, 뒷면 직함·짧은 골드 바·세로 구분선·QR 테두리·우하단 곡선입니다.
지금 파일은 4도 인쇄용이라 별색이 들어 있지 않습니다 — 박으로 가시면 별색 분판 파일을 따로 만들어 드립니다.

## 5. 용지 제안

- 시안의 질감을 살리려면: **흑지(블랙 종이) 300g 이상 + 흰색·금박** 또는 레더·린넨 등 엠보 용지
- 일반 4도 인쇄라면: 스노우지·랑데뷰 300g 이상 + **무광 코팅** (검정 배경의 지문·반사·뒷묻음 줄이기)
- 검정 배경 명함은 재단면이 하얗게 보이므로 **엣지 컬러(측면 색) 또는 검정 합지**를 권장
